🚀 Platform Overview

AI Learning Lab is a state-of-the-art desktop suite engineered to transform how developers learn modern computing concepts. Combining interactive visual explainers, W3Schools-style live editable sandboxes, and automated situational challenges, the application bridges theory with real-world execution.

💡 Core Philosophy

No passive video watching. Every single lesson presents dynamic interactive diagrams, editable code examples that execute in real-time, and scenario-based terminal challenges.

💻 System Requirements

Thanks to Tauri's lightweight Rust core, AI Learning Lab uses under 90MB of RAM and boots in milliseconds.

Platform Minimum OS Architecture Disk Space
Windows Windows 10 / 11 x64, ARM64 150 MB
macOS macOS 11.0 (Big Sur)+ Apple Silicon (M1/M2/M3), Intel 180 MB
Linux glibc 2.31+ (Ubuntu 20.04+) x86_64, aarch64 120 MB

📦 Installation Guide

Windows Installation

Download the .exe installer from the downloads hub and run the setup wizard. Or install via Winget:

winget install RajdeepMudiar.AILearningLab

macOS Installation

Open the downloaded .dmg file and drag the AI Learning Lab app into your Applications folder. If running on Apple Silicon, the universal binary will execute natively.

Linux Installation (AppImage)

chmod +x AI-Learning-Lab-x86_64.AppImage
./AI-Learning-Lab-x86_64.AppImage

📚 Curriculum Tracks & Syllabi

The curriculum contains 28 courses and 79 lessons with interactive quizzes and skill progression:

  • AI & Machine Learning (6 Courses): Python & NumPy Computing, Mathematics & Derivatives, Classical ML (Regression & Decision Trees), Deep Learning Perceptrons, Computer Vision CNNs, and Transformers & RAG Agents.
  • Full-Stack Web Dev (7 Courses): HTML5 Architecture, CSS3 Responsive Grid, JavaScript V8 Engine, React 18 & Zustand, Node.js REST APIs, and Next.js SSR Web Performance.
  • App Development (6 Courses): React Native Foundations, Mobile Gestures & Reanimated 3, Offline-First SQLite & MMKV, Flutter Impeller Engine, and Push Notifications & App Store Release.
  • System Design (5 Courses): Distributed Systems Foundations, Layer 4/7 Load Balancers & Gateways, Redis Caching & Kafka Event Streams, and Sharding & Raft Consensus.
  • Git & GitHub (4 Courses): Git Core Internals & DAG, Branching & Interactive Rebase, Pull Request Reviews, and Automated GitHub Actions CI/CD.

⚡ Interactive Sandboxes & W3Schools-like Live Editor

Every lesson includes an embedded, responsive code sandbox. Users can edit HTML, CSS, JavaScript, Python, or Dart directly inside the browser/desktop window, click Run Code, and instantly see rendered live HTML or terminal stdout in real-time.

🐙 Git Interactive Terminal & Branch Tree Graph

The Git Laboratory features an interactive xterm-powered terminal with command history (Up/Down arrow navigation). As you execute git checkout -b feature, git commit -m "...", and git rebase main, the interactive SVG commit graph draws branch nodes and merge commits in real-time.

🏗️ Tech Stack & Architecture

AI Learning Lab is built with high-performance modern technologies:

  • Desktop Shell: Tauri 2.0 (Rust backend with WebKit/WebView2).
  • Frontend UI: React 18, Vite, Lucide Icons, Canvas Visualizers.
  • Backend Engine: Python 3.13, FastAPI, Motor AsyncIO.
  • Database Persistence: MongoDB with offline-first caching.

🤝 Local Setup & Contributing

To run the full stack locally for development:

# 1. Clone repository
git clone https://github.com/Rajdeep-Mudiar/AI_Learning_Desktop_App.git
cd AI_Learning_Desktop_App

# 2. Start backend server
cd apps/backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python main.py

# 3. Start desktop frontend in another terminal
cd apps/desktop
npm install
npm run tauri dev
